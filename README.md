# שינויים בסככות התחנה המרכזית בבאר שבע

אתר עירוני למציאת סככה חלופית בתחנה המרכזית בימי עבודות התשתית **16–18.11.2026**.

אתר חי: https://kav-hasakhot.vercel.app

## שימוש

1. בחירת יום נסיעה  
2. הקלדת מספר קו או יעד (או בחירה מהירה)  
3. אם יש כמה כיוונים — בחירת יעד  
4. הצגת סככה גדול + הדגשה במפה האינטראקטיבית  

## מבנה

| קובץ | תפקיד |
|------|--------|
| `index.html` | מבנה העמוד |
| `styles.css` | עיצוב עירוני (Mobile First) |
| `js/data.js` | מקור נתונים מרכזי: ימים, שינויים, סככות, גיאומטריית מפה |
| `js/engine.js` | חיפוש, נרמול קווים, פתרון סככה |
| `js/map.js` | מפת SVG אינטראקטיבית |
| `js/app.js` | ממשק משתמש |
| `tests/lookup.test.mjs` | בדיקות תקינות מחייבות |

## בדיקות

```bash
node tests/lookup.test.mjs
```

## מקורות

הודעת עיריית באר שבע / דן באר שבע ותרשימי הסככות המצורפים.
